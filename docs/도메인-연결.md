# 도메인 연결 가이드 (자동 HTTPS)

살롱 데일리를 도메인으로 여는 방법입니다. **서버 1대 + 도메인 1개**만 있으면
브라우저 주소창이 도메인(https://...)으로 뜨고, **자동 HTTPS(SSL)** 가 적용됩니다.

---

## 1. 도메인 준비

- 도메인을 하나 구매하거나 보유하세요. (가비아, 카페24, 클라우드플레어 등)
- 예: `salon-mybeauty.kr`, 또는 기존 보유 도메인의 하위 도메인 `salon.mydomain.kr`

---

## 2. 서버에 배포 (Docker)

사용자 서버(집 NAS/시놀로지/클라우드)에 프로젝트 폴더를 두고:

```bash
# Caddyfile 을 열고 최상단 '도메인주소' 를 실제 도메인으로 변경
cd salon-daily
docker compose -f docker-compose.prod.yml up -d --build
```

- Caddy가 80/443 포트에서 HTTPS 인증서를 자동 발급·갱신합니다.
- 앱 데이터는 `./data/salon.db` 에 유지됩니다.

---

## 3. DNS 레코드 설정 (핵심)

서버의 **공인 IP(예: 123.45.67.89)** 를 도메인의 A 레코드에 연결합니다.

### 가비아
- 도메인 → DNS 관리 → 호스트(A 레코드) 추가
- 호스트: `@` (또는 하위도메인 `salon`) / IP: `서버 공인IP` / TTL: 기본

### 카페24
- 카페24에서 도메인 연결 또는 외부 호스팅 IP 연결
- A 레코드: 호스트 `@` (또는 `salon`) → `서버 공인IP`

### Cloudflare
- 도메인을 Cloudflare에 추가 → DNS → Add record
- Type `A`, Name `@` (또는 `salon`), IPv4 `서버 공인IP`, Proxy: Off(오렌지 꺼짐·DNS only 권장)

> 기록이 퍼지는 데 5분~24시간 걸릴 수 있습니다. 그 후 https://도메인 으로 접속하면
> Caddy가 자동으로 인증서를 발급해 **https(자물쇠)** 가 걸립니다.

---

## 4. 확인 & 주의

- 접속: `https://<도메인>` → 로그인(owner/매니저) → 첫 로그인 후 비밀번호 변경
- 80/443 포트를 열어 두어야 인증서 발급이 됩니다 (방화벽/공유기 포워딩).
- 이미 다른 서비스가 80/443을 쓰면 `docker-compose.prod.yml` 포트를 조정하세요.

---

## 5. 도메인 없이 지금 바로 쓰려면?

- **Cloudflare Quick Tunnel**(무료, HTTPS): 서버에서 아래 한 줄 실행
  ```bash
  cloudflared tunnel --url http://localhost:4000
  ```
  → `https://<random>.trycloudflare.com` 이 발급됩니다(재시작 시 주소 변경).
- 짧고 안정적인 주소가 필요하면 도메인 구매 + 위 2·3단계를 권장합니다.
